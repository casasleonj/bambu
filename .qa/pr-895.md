#### El defecto original, comprobado

El issue describe que el mensaje «El nombre es obligatorio» aparecía **recién después** de corregir el teléfono, porque la validación propia se detenía en el primer fallo. En el paso 6, `aviso_app: false` y el globo del navegador en el campo Nombre confirman que ahora bloquea **antes** de llegar a esa validación.

#### Verificación en base de datos, no sólo en pantalla

```sql
SELECT nombre, telefono FROM "Cliente" WHERE nombre LIKE 'Cliente QA%';
-- Cliente QA 8883 | 5730…
```

El paso 7 se validó contra Postgres, no por lo que mostrara la UI. La captura `4-creado.png` muestra la lista paginada «1-5 de 5»; el cliente recién creado queda en la página siguiente por el orden, y por eso se comprobó aparte en la base antes de limpiarla.

#### Nota sobre el idioma del globo

En la primera corrida el mensaje salió en inglés («Please fill out this field»). Se investigó aislado: la página declara `lang="es"`, y el binario «Chrome for Testing» responde en el idioma del **navegador**, no del documento. Con `--lang=es` el mensaje es **«Completa este campo»**. No es un defecto del producto; era la configuración del entorno de prueba.

#### Incidencias del entorno (no del cambio)

1. `prisma migrate deploy` falla en este repo: dos migraciones iniciales (`0_init` y `20260430061138_init`) crean los mismos tipos ENUM. La CI no usa ese comando; el entorno se levantó como ella: `prisma db push` → `scripts/aplicar-migraciones-sql-crudas.sh` → seed.
2. El cliente Prisma de `node_modules` estaba desfasado (`Pago.correcciones` ausente) y hacía fallar el dashboard con `PrismaClientValidationError`. Se resolvió con `npx prisma generate`.
3. Redis no estaba levantado y el servidor registraba `ECONNREFUSED 6379` en cada request. Se instaló y arrancó.

#### Observaciones fuera del alcance de #811, no corregidas

- En móvil el globo nativo se superpone visualmente al campo de teléfono. Es comportamiento del navegador, no del layout; sin desborde horizontal.
- El API rechaza teléfonos duplicados con 409 y el formulario muestra «Ya existe un cliente con ese teléfono». Funciona; se anota como evidencia de que la validación de servidor sigue activa.
