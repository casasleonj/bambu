**Regla seguida:** jerarquía de fuentes — ADRs congelados (`docs/adr/`) → Planes/políticas de dominio ya aprobados (`docs/pedidos/*.md`) → estado técnico verificado de `main` → el Plan Maestro nuevo.
**No modifica schema/endpoints/UI/lógica de dominio.** Es solo análisis. Verificado con lectura directa de código + ADRs, no solo con memoria de sesiones previas (la memoria del proyecto estaba desactualizada en varios puntos — ver §7).

**Regla fundamental aplicada:** si una capacidad ya existe y satisface la misma invariante, no se construye otra implementación. Se verifica, corrige o activa la existente.
