# Servicios y contratos compartidos · reglas locales

Para los archivos bajo `src/lib/`, **aplica el contrato local** de `src/lib/AGENTS.md` además de `AGENTS.md` raíz. Antes de implementar, leer la guía local, rescatar cláusulas críticas pertinentes y contrastar estado técnico en `main`. No tratar el texto histórico como sustituto del código. Las aprobaciones de UI, planes y merge del PO continúan vigentes. Esta regla existe para asegurar descubrimiento en Claude Code; no reemplaza ni duplica el contrato canónico.
